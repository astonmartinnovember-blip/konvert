# Konvert
PNG / JPEG / WebP конвертері; сурет → PDF; фото немесе PDF → өңделетін Word / TXT.
Қазақша, орысша, ағылшынша OCR. Файлдар браузерде өңделеді.

## GitHub-қа жүктеу
1. ZIP-ті ашып, `konvert-github` папкасына кір.
2. GitHub-та `konvert` деген жаңа Public репозиторий жаса (негізгі тармақ — main).
3. Add file → Upload files: папканың ішіндегі барлық файлдар мен папкаларды жүкте. ZIP-тің өзін жүктеме. package.json репозиторий түбінде болуы керек.
4. `.github/workflows/pages.yml` жүктелгенін тексер. Жоқ болса, Add file → Create new file арқылы дәл осы жолмен файл жаса да, архивтегі pages.yml мазмұнын көшір.
5. Settings → Pages → Build and deployment → Source → GitHub Actions таңда.
6. Actions → Publish Konvert → Run workflow бас. Бұрын Pages қосылмағандықтан қате шықса, қайта іске қос.
7. Жасыл белгі шыққаннан кейін сайт сілтемесін Settings → Pages бөлімінен ал.

## Компьютерде іске қосу
Node.js 24 қажет:
```sh
npm ci
npm run build
```
Python орнатылған болса:
```sh
python -m http.server 8080 --directory dist
```
http://localhost:8080 аш. index.html файлын екі рет басып ашу worker-лерді іске қоспайды.

## Шектеулер
- Бір файл: 20 МБ дейін; PDF: 30 бет; сурет: 40 мегапиксель.
- Бірінші OCR жүктелуінде тіл модельдері сайттан жүктеледі; интернет қажет.
- Word-та мәтін өңделеді, бірақ күрделі дизайн мен кестелер дәл сақталмайды.
- Танылған мәтінді тексер: әсіресе аты-жөн, сандар, қазақша әріптер.
- Тоқтату ағымдағы бет аяқталған соң орындалады.

## Құрамы
public/ — интерфейс; app-source.js — конвертация; build.cjs — жинау;
.github/workflows/pages.yml — GitHub Pages жариялау; package-lock.json — бекітілген тәуелділіктер.
Worker/OCR жолдары GitHub Pages ішкі жолдарына бейімделген.
Үшінші тарап пакеттері өз лицензияларымен таратылады.
Бұл архив GitHub-қа әлі жүктелген жоқ. Жариялау workflow-ы өз аккаунтыңда орындалады.
